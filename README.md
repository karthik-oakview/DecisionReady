
# DecisionReady

DecisionReady is an emergency preparedness app
designed for South Carolina.

## Features
- Weather conditions and emergency alerts
- Personalized emergency preparedness guidance
- Emergency readiness assessment
- What-If Explorer
- Interactive emergency resources map
- Fictional emergency simulation scenarios

## Technologies
- React Native
- Expo
- JavaScript
- Weather and emergency alert APIs
- React Native Maps

## Developer
Developed independently for the
2026 Congressional App Challenge.

## Disclaimer
DecisionReady is an educational prototype.
It is not a replacement for official
emergency alerts or instructions.
